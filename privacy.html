Конфиденциальность AIRUSS Browser

Обновлено 22 ноября 2026 года · версия 1.0.2

Локальные данные

История, закладки, настройки, cookies и профиль WebView2 сохраняются на компьютере пользователя в %LOCALAPPDATA%\AIRUSS\Browser. Удаление приложения может не удалить профиль автоматически.

Доступ к профилю ограничен текущим пользователем Windows и SYSTEM. История, закладки, настройки, сессия вкладок и переписка AI защищены Windows DPAPI. Кэш остаётся локальным и не загружается AIRUSS на сервер. Не весь кэш зашифрован: приложения с правами текущего пользователя и администратор могут получить к нему доступ. Старые JSON-файлы мигрируют при чтении; прежняя версия AIRUSS после этого не сможет их открыть.

Посещаемые сайты

Сайты и Microsoft WebView2 обрабатывают данные по собственным правилам. AIRUSS не обещает анонимность и не является заменой Tor Browser.

Перевод сайтов

При включении перевода видимый текст страницы передаётся Google Translate. Не переводите страницы с конфиденциальными сведениями. Автоперевод отключён по умолчанию.

Общий AI-помощник

Когда вы сами отправляете сообщение в режиме «AIRUSS AI», текст запроса передаётся на сервер AIRUSS (Supabase), затем в модель Яндекса для формирования ответа. Для ограничения нагрузки сервер обрабатывает технический идентификатор устройства и данные сетевого подключения. Ключ сервиса Яндекса хранится на сервере, а не в установщике. Сам по себе этот режим не отправляет cookies, историю, вкладки или локальные документы.

Другие AI-провайдеры

При выборе другой облачной модели и отдельных функций анализа страницы данные могут передаваться соответствующему сервису. Локальные модели обрабатывают запросы локально согласно настройкам. Не отправляйте в AI пароли, API-ключи и другие секреты.

Резюме страницы и сравнение вкладок отправляют ограниченный фрагмент видимого текста после подтверждения с указанием провайдера. Обычный вопрос не содержит контекста браузера. Кэш, cookies, HTML и локальные файлы в контекст не включаются. Внутренние и известные защищённые страницы, локальная сеть и страницы с полем пароля исключаются. Видимый текст может содержать личные данные — проверяйте его перед согласием.

История AI-переписки

Беседы разных моделей и подключений, включая смену облачного ключа, разделены. При переключении отменяется ответ предыдущей беседы. Между запусками история по умолчанию не сохраняется. Сохранение включается для конкретного подключения; файл защищается Windows DPAPI с привязкой к пользователю Windows, компьютеру, профилю и подключению. На общем компьютере оставьте сохранение выключенным. Старый общий файл остаётся на компьютере, но автоматически не открывается и не назначается новому пользователю.

Голос и погода

Микрофон включается пользователем. Локальное распознавание Whisper/Vosk не отправляет звук в облако. При явном выборе Yandex SpeechKit запись или текст для озвучивания передаются Яндексу. Погода на новой вкладке использует выбранный город и API Open-Meteo; GPS автоматически не включается.

Обновления и диагностика

Обращения к внешним сервисам могут передавать IP-адрес и технические параметры соединения. Личный API-ключ пользователя не включается в официальный установщик.

Обратная связь

Сообщить о проблеме можно в публичном разделе вопросов GitHub. Не прикладывайте к обращению личные данные, ключи и переписку.
