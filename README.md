# AIRUSS Browser — загрузки для Windows

Публичные установочные файлы и документация AIRUSS Browser. Исходники проекта хранятся отдельно и не публикуются в этом репозитории.

## Скачать
Скачайте AIRUSS Browser 1.0.1 для Windows x64: https://github.com/ivan19326/airuss-browser-downloads/releases/tag/v1.0.1

- Windows 10/11 x64; устанавливать .NET отдельно не нужно.
- Установщик включает официальный WebView2 bootstrapper Microsoft.
- Установщик пока без цифровой подписи издателя; не отключайте защиту Windows.
- Проверяйте SHA-256 файла Setup.exe по приложенному SHA256SUMS.txt.

## Возможности
В выпуске 1.0.1 исправлены всплывающие окна, POST-переходы и blob-ссылки, усилена изоляция сайтов от внутренних команд браузера. История, закладки, настройки и сессия шифруются Windows DPAPI. Кэш остаётся в локальном профиле с ограничением доступа; полного шифрования кэша и защиты от программ с правами текущего пользователя нет. Для отправки текста страницы в облачный AI запрашивается подтверждение.

Вкладки, история, закладки, загрузки, перевод сайтов на русский и AI-панель. Общий AIRUSS AI доступен без личного API-ключа и с ограничениями по количеству запросов; другие AI-провайдеры можно подключить самостоятельно. Перевод отправляет текст страниц стороннему сервису.

## Важное
Приложение поставляется без гарантии бесперебойной работы. Не запускайте установщики с неофициальных зеркал. Windows SmartScreen может предупредить о программе без репутации подписи. Мы не просим отключать защиту Windows.
