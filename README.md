# AIRUSS Browser — загрузки для Windows

Публичные установочные файлы и документация AIRUSS Browser. Исходники проекта хранятся отдельно и не публикуются в этом репозитории.

## Скачать
Откройте раздел Releases и выберите свежую бета-версию Windows x64.

- Windows 10/11 x64; устанавливать .NET отдельно не нужно.
- Установщик включает официальный WebView2 bootstrapper Microsoft.
- Если установщик пока не имеет подписи издателя, выпуск явно отмечен как beta / unsigned.
- Проверяйте SHA-256 файла Setup.exe по приложенному SHA256SUMS.txt.

## Возможности
Вкладки, история, закладки, загрузки, перевод сайтов на русский и AI-панель. Для AI нужно настроить собственную модель/провайдера. Перевод отправляет текст страниц стороннему сервису.

## Важное
Пробная версия не имеет гарантий стабильности. Не запускайте установщики с неофициальных зеркал. Windows SmartScreen может предупредить о программе без репутации подписи. Мы не просим отключать защиту Windows.
